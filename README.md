# 🦊 Fox Drop

A Fortnite tracker for Android: today's Item Shop, new cosmetics, news, tournaments and server status, with alerts when something on your wishlist hits the shop, a new patch drops, or the servers go down.

## Install

1. On your Android phone, open **[FoxDrop.apk](https://github.com/LateralDamage/fox-drop/releases/latest/download/FoxDrop.apk)**.
2. Tap the download and choose **Install**. If asked, allow your browser to install apps.
3. If Play Protect says "unknown app", choose **More details → Install anyway**.
4. Open Fox Drop and tap **Allow** for notifications.

Fox Drop checks every 15 minutes. On Samsung phones, set Settings → Apps → Fox Drop → Battery to **Unrestricted** so the checks keep running.

Data comes from [fortnite-api.com](https://fortnite-api.com), [status.epicgames.com](https://status.epicgames.com) and Epic's public game content feed. Not affiliated with Epic Games.
