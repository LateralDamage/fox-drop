Fox Drop

Fortnite shop, news & server alerts

⬇ Download Fox Drop

Android phones and tablets · 1.7 MB · free

How to install

  1. Tap Download Fox Drop above.
  2. Open the download and tap Install. If it asks, allow your browser to install apps.
  3. If Play Protect says "unknown app", tap More details → Install anyway.
  4. Open Fox Drop and tap Allow for notifications.

What it does

  • Today's Item Shop, with a countdown to the next reset
  • A wishlist: get pinged the day a skin you want hits the shop
  • New skins and cosmetics as they're added to the game
  • News, Epic notices and tournaments
  • Server status, plus alerts for downtime and when the servers are back

Samsung phones

Set Settings → Apps → Fox Drop → Battery to Unrestricted so alerts keep coming.

Not affiliated with Epic Games. Data from fortnite-api.com and status.epicgames.com.
